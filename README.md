# Александра Брагинская — портфолио

Сайт художницы на React + TypeScript + Vite. Сохранены галерея из 20 картин, 6 новостей, выставки, контакты, параллакс и лупа. Интерфейс адаптирован для телефона, планшета и компьютера, поддерживает системное уменьшение движения.

## Требования и запуск

Node.js 22.18+ (рекомендуется 24 LTS), pnpm 11.25.0.

```sh
corepack enable
corepack prepare pnpm@11.25.0 --activate
pnpm install --frozen-lockfile
pnpm dev
```

Адрес разработки — http://127.0.0.1:5173.

### PowerShell: команда pnpm не найдена

На компьютере с установленным Node.js можно установить pnpm командой `npm.cmd install --global pnpm@11.25.0`, затем открыть новый PowerShell.

На текущем компьютере доступны также инструменты среды Codex. Чтобы временно подключить их в обычном PowerShell (без изменения системного PATH), выполните:

```powershell
$runtime = "$env:USERPROFILE\.cache\codex-runtimes\codex-primary-runtime\dependencies"
$env:Path = "$runtime\node\bin;$runtime\bin\fallback;$env:Path"
pnpm.cmd install --frozen-lockfile
pnpm.cmd dev
```

Этот вариант зависит от установленной среды Codex; для других компьютеров используйте обычную установку Node.js и pnpm.

```sh
pnpm format:check
pnpm typecheck
pnpm test
pnpm build
pnpm preview
```

Результат сборки — `dist/`. Его можно разместить на обычном статическом хостинге. Обе страницы (`index.html` и `painting.html?id=…`) собираются отдельно; серверный роутер не нужен. Относительные пути позволяют размещение в подкаталоге. Публикация автоматически не выполняется.

## Браузерные тесты

```sh
pnpm exec playwright install chromium
pnpm test:e2e
```

Для установленного Google Chrome можно задать переменную `PLAYWRIGHT_CHANNEL=chrome` вместо загрузки Chromium.

Тесты запускаются на production-сборке, поэтому сначала выполните `pnpm build`. Покрыты настольная и мобильная ширина, навигация, раскрытие списков, карусель, страница картины, лупа, ошибочные ID, смена ширины, уменьшение движения, ошибки JS и HTTP. HTML-отчёт сохраняется в `playwright-report/`, трассировки ошибок — в `test-results/`.

## Структура и контент

- `src/components/` — первый экран, карусель, редакционные разделы и страница картины.
- `src/hooks/parallax.js` — движок параллакса с очисткой обработчиков, кадров и таймеров при размонтировании.
- `src/styles/` — базовое оформление, адаптивность, первый экран, картина и обновление дизайна.
- `public/gallery.json`, `public/news.json` — порядок карточек.
- `public/data/` — тексты и метаданные картин; `public/data/news/` — новости.
- `public/img/` — оригиналы, слои первого экрана и превью.
- `tests/` — проверки контента и браузерные сценарии.
- `work_notes/react-migration/` — состояние работы и результаты проверок.

JSON включается в приложение при сборке. После редактирования контента нужна новая сборка. Для новой картины добавьте уникальный ID в `gallery.json`, JSON с полями `title`, `year` (необязательно), `materials`, `size`, `price`, `description` и оригинал `img/<id>.jpg`. Затем выполните:

```sh
pnpm previews
```

Превью WebP двух размеров хранятся в репозитории. При ошибке обработки генератор завершится с ненулевым кодом. Новость содержит `title`, `date` в формате `YYYY-MM-DD`, `description`, необязательный HTTPS `link` и изображение `img/news/<id>.jpg`.

Переменные окружения и секреты для текущей версии не нужны. `.env*` исключены из Git; безопасный `.env.example` при необходимости разрешён. Не помещайте секреты в переменные `VITE_*`: они доступны браузеру.

## Известные ограничения

В исходнике все даты новостей имеют значение `2026-30-1`. Они сохранены без изменений; интерфейс показывает «Новости мастерской» до уточнения дат. Датчики телефона требуют HTTPS (или localhost), поддержки браузера и, на iOS, разрешения пользователя. Эмуляция мобильного экрана не заменяет проверку реального гироскопа.

`node_modules/` снят с отслеживания Git, локальные зависимости сохранены. Единственный lock-файл — `pnpm-lock.yaml`.

## GitHub Pages

Workflow `.github/workflows/pages.yml` проверяет и собирает проект при push в `main`, затем публикует только `dist/` через GitHub Actions. В настройках репозитория **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**.

Адрес проекта: https://faust-man.github.io/Alexandra-Braginskaya/ . Сборка использует относительные пути и сохраняет адреса `painting.html?id=…`. Заметки `work_notes/` исключены из Git и публикации.

## Кеш изображений

В production Service Worker сохраняет уже загруженные картины, превью, новости и слои первого экрана в Cache Storage браузера. Повторные запросы получают сохранённое изображение сразу, одновременно выполняется фоновая проверка обновления. Изменённая версия используется при следующем запросе. HTML и код приложения этим кешем не перехватываются.

Кеш ограничен 80 изображениями и областью текущего сайта (включая подкаталог GitHub Pages). Все оригиналы заранее не скачиваются. При недоступном или заполненном хранилище сайт продолжает работать через сеть. Браузер может удалить кеш при очистке данных сайта или нехватке места. Для проверки локально используйте `pnpm build` и `pnpm preview`; в режиме `pnpm dev` Service Worker не регистрируется. Полноценный запуск сайта без сети не предусмотрен — кешируются только изображения.
